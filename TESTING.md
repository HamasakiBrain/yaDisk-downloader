# Проверки

`npm.cmd run check`, `npm.cmd test` (10 unit), `npm.cmd run test:browser` (6 сценариев в Chromium с загруженным расширением, локальные фикстуры и подменённые ответы Яндекса).

## Проверено автотестами

- Штатный ZIP Яндекса: 5 файлов, вложенная папка исключена, выделение и кнопка «Скачать».
- Виртуализованный список с ленивой подгрузкой: собраны все 100 ID, в том числе когда вкладка Диска не на переднем плане.
- Публичная папка через API: 100 файлов + файл во вложенной папке (путь `nested/...` в ZIP), одинаковые кириллические имена, 7 форматов, байт в байт.
- Частичный сбой: 2 ответа 403, архив из 3 файлов валиден, ошибки перечислены.
- Пустая папка: запуск невозможен.
- Отмена во время скачивания: нет состояния успеха.
- Unit: allowlist доменов, разбор публичных путей, уникальные имена, сопоставление загрузок, пагинация API, усечённые потоки.

## Не проверено

- Реальный аккаунт Яндекс Диска: разметка `content.js` проверена только на фикстурах. При ошибке распознавания используйте кнопку «Диагностика».
- Реальные лимиты, CAPTCHA, истёкшая сессия, файлы больше квоты OPFS.
- Другие одновременные загрузки из того же раздела (см. README).
