# Приватность

Расширение не содержит аналитики и не отправляет содержимое файлов сторонним серверам. Оно использует открытую вкладку Яндекс Диска, штатные элементы выделения и скачивания и временные ссылки, выдаваемые сайтом. Для публичных ссылок список файлов и ссылки скачивания запрашиваются через официальный публичный API Яндекс Диска (`cloud-api.yandex.net`) без авторизации. Приватные API не вызываются. Расширение не является продуктом Яндекса.

Логины, пароли, cookies и токены расширение не читает и не сохраняет. Сессионная авторизация передается браузером при запросах к Яндексу. Временные ссылки скачивания находятся только в оперативной памяти на время операции. В `chrome.storage.session` хранятся имена, размеры, идентификаторы файлов, адрес открытого раздела и состояние операции; эти данные очищаются при завершении сессии браузера или удалении расширения.

Локальный ZIP и один промежуточный файл записываются в приватное временное хранилище расширения (OPFS). После сохранения, отмены или ошибки временные данные удаляются. После аварийного завершения браузера оставшиеся временные данные удаляются при следующей локальной упаковке. Готовый архив сохраняется в загрузки Chrome. История загрузок управляется самим Chrome.

Разрешения: `activeTab` и `scripting` — чтение и управление списком после открытия popup; `downloads` — наблюдение, сохранение ZIP и отмена связанных загрузок; `storage` — состояние между открытиями popup; `offscreen` — потоковая упаковка вне popup; `alarms` — проверка зависшего ожидания ZIP. Доступ к узким группам доменов Диска и CDN Яндекса нужен для скачивания файлов. Нет доступа ко всем сайтам, cookies и истории посещений.
